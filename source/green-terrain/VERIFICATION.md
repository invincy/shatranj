# Dark green terrain and balanced camps

Surrounding terrain uses a moss-green palette with darker green worn paths instead of brown dirt. Grass color and coverage updated on both sides. Rendered match views at phone and desktop sizes and title views checked; added tents remain outside playable squares. Piece-readability and title navigation/layout assertions passed. Web export and PWA checks passed. Actual mobile GPU performance not measured.
