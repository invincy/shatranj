Stockfish engine

Build with the upstream Emscripten instructions and node build.js --single-threaded --lite -f. See the source README for dependencies and network download instructions.

Shatranj difficulty 1–10 maps to Stockfish Skill Level 0–20 (rounded), with depth caps 4–13 and thinking budgets 350–1250 milliseconds. Levels are approximate, not Elo ratings; strength varies by device and position.
